# Jōyō Kanji List (常用漢字)

Complete list of the **2,136** characters in the [2010 Jōyō Kanji Hyō](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji.html) (常用漢字表), in official publication order (掲載順).

## Columns

| Column | Status | Notes |
| --- | --- | --- |
| Kanji number | Filled | Official 掲載順 (1–2136), gojūon order starting at 亜 |
| Kanji | Filled | Official form (includes 𠮟 塡 剝 頰) |
| Kun Readings | Filled | From KANJIDIC2 via [kanji-data](https://github.com/davidluzgouveia/kanji-data); `.` marks okurigana, `-` marks bound forms |
| On Readings | Filled | Same source |
| Radical makeup | Filled | Component elements from [KRADFILE](https://www.edrdg.org/krad/kradinf.html) (not only the classical classifying radical) |
| Common English | Filled | Primary KANJIDIC2 glosses |
| RTK number | Empty | Remembering the Kanji — for a follow-up pass |
| KLC number | Empty | Kodansha Kanji Learner's Course — for a follow-up pass |
| WaniKani lesson | Empty | For a follow-up pass |

# Jōyō Kanji List (常用漢字)

Complete list of the **2,136** characters in the [2010 Jōyō Kanji Hyō](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji.html) (常用漢字表), in official publication order (掲載順).

## Columns

| Column | Status | Notes |
| --- | --- | --- |
| Kanji number | Filled | Official 掲載順 (1–2136), gojūon order starting at 亜 |
| Kanji | Filled | Official form (includes 𠮟 塡 剝 頰) |
| Kun Readings | Filled | From KANJIDIC2 via [kanji-data](https://github.com/davidluzgouveia/kanji-data); `.` marks okurigana, `-` marks bound forms |
| On Readings | Filled | Same source |
| Radical makeup | Filled | Component elements from [KRADFILE](https://www.edrdg.org/krad/kradinf.html) (not only the classical classifying radical) |
| Common English | Filled | Primary KANJIDIC2 glosses |
| RTK number | Filled (2136/2136) | Remembering the Kanji **6th edition** frame number ([sdcr/heisig-kanjis](https://github.com/sdcr/heisig-kanjis)) |
| KLC number | Filled (1984/2136) | Kodansha Kanji Learner's Course entry number; blank where the source has no index |
| WaniKani lesson | Filled (1963/2136) | WaniKani level 1–60; blank for Joyo characters not in WK |

## Sources

- Official order: [mimneko/kanji-data 常用漢字.csv](https://github.com/mimneko/kanji-data) (文化庁 常用漢字表)
- Readings & meanings: [davidluzgouveia/kanji-data](https://github.com/davidluzgouveia/kanji-data) (`kanji-jouyou.json`, derived from KANJIDIC2)
- Radical components: EDRDG KRADFILE / [hoffmannjp/krad-unicode](https://github.com/hoffmannjp/krad-unicode)
- RTK numbers: [sdcr/heisig-kanjis](https://github.com/sdcr/heisig-kanjis) (`id_6th_ed`)
- KLC numbers: [Mononofu/kanji_poster](https://github.com/Mononofu/kanji_poster) (`Kanji Learner Course Index`)
- WaniKani levels: [davidluzgouveia/kanji-data](https://github.com/davidluzgouveia/kanji-data) (`wk_level`)

KANJIDIC2 and KRADFILE are copyright the Electronic Dictionary Research and Development Group and used under their licence terms: https://www.edrdg.org/edrdg/licence.html

RTK, KLC, and WaniKani numbers come from community cross-reference indexes (not official APIs). Gaps are left blank where a source has no entry.

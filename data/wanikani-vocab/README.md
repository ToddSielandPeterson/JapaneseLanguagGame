# WaniKani Vocabulary List

All vocabulary items taught in [WaniKani](https://www.wanikani.com/) (levels **1–60**), pulled from the community [ebieki](https://github.com/fasiha/ebieki) dataset.

## Columns

| Column | Notes |
| --- | --- |
| Lesson | WaniKani level (1–60) |
| Lesson position | Order within that lesson |
| Word | Vocabulary characters as taught |
| Pronunciation | Kana reading(s); multiple readings separated by `; ` |
| English | Primary English glosses from JMdict (via ebieki), not WaniKani’s copyrighted meanings |

## Coverage

- **6345** vocabulary items across levels 1–60
- English meanings use open JMdict definitions (ebieki’s approach), so they may differ slightly from the short glosses shown inside WaniKani

- WaniKani item membership/order is community-exported; confirm against WaniKani if you need a specific content revision

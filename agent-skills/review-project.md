# Review this project

Fill the sections, then press **Execute**.

## Goal
High-level review of the repository: architecture risks, missing tests, and the top 5 fixes.

## Scope
The project root. Prefer reading over rewriting.

## Constraints
- Do not start a large rewrite.
- Stay in this branch only.
- Do not add dependencies.

## Steps
1. Inspect layout (build files, src, tests).
2. Note the top risks and missing tests.
3. Recommend the next job (one concrete follow-up).

## Done when

- [ ] Top 5 fixes, ordered
- [ ] One recommended next job

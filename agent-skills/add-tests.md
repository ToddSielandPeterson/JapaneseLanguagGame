# Add tests

Fill the sections, then press **Execute**.

## Goal
Add tests for the behavior described below (or for the open file).

## Scope
Test sources for the target module. Production code only if a tiny seam is required.

## Constraints
- Use the project's existing test framework.
- Do not change production code unless a tiny seam is required.
- Do not add dependencies unless required.
- Match existing style.

## Steps
1. Identify the target module / class / function.
2. Add tests for the described behavior.
3. Say how to run them.

## Done when
- [ ] New tests exist
- [ ] You say how to run them
- [ ] They fail on the old bug / pass on the fix (if applicable)

# Fix a bug

Fill the sections, then press **Execute**.

## Goal
Describe the bug (expected vs actual) and where you saw it.

## Scope
Only the files needed for the smallest correct fix.

## Constraints
- Smallest correct fix.
- Add or update a test if the project has a test suite.
- Do not rewrite unrelated code.
- Match existing style.

## Steps
1. Reproduce or confirm the failure.
2. Fix the root cause.
3. Add or update a test if possible.

## Done when
- [ ] Repro no longer fails
- [ ] Change is explained
